# Museum Blind Box Consumer Insights Dashboard

Interactive dashboard for the project. It uses the same code-generated
results as the Python/SQL analysis and presents four views:

- Overview
- Products
- Customer Voice
- Model Quality

The visual system is based on the project cover: warm cream, coral pink, golden yellow, sky blue,
lavender, mint, and deep museum green.

```bash
npm install
npm run dev
npm run build
```

The dashboard is descriptive and exploratory. It does not support causal, authenticity, revenue,
demand-forecasting, or production sentiment-accuracy claims.
