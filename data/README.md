# Public data

This directory separates recruiter-reviewable data from private or third-party source files. The
public tables are generated by `make public-data`; they are not manually edited.

## Files available on GitHub

| File | Rows | Purpose | Excluded fields |
|---|---:|---|---|
| `public/products_anonymized.csv` | 150 | Price, format, store signal, sales coverage, and K-Means segment analysis | Product title, seller name, listing URL, HTML snapshot |
| `public/review_model_outputs_anonymized.csv` | 500 | Sentiment, aspect, and LDA topic outputs | Chinese review text and any source-level identifiers |
| `public/sentiment_evaluation_anonymized.csv` | 180 | Human-label versus SnowNLP evaluation | Chinese review text and reviewer notes |
| `public/aggregates/*.csv` | varies | Model selection, segment profiles, sentiment metrics, and dashboard summaries | Row-level text and seller information |

The product and review tables are independent and must not be joined at product level. The review
source does not retain a defensible product identifier.

## Data retained locally

- `raw/legacy/`: immutable undergraduate spreadsheets and checksums;
- `raw/external/`: downloaded HTML/workbook snapshots governed by their original terms;
- `annotations/`: the private human-review workspace;
- `interim/` and `processed/`: complete pipeline outputs, including Chinese text and source fields.

These files are intentionally ignored by Git. Source provenance and licenses are documented in
the two `PROVENANCE.md` files and in [`THIRD_PARTY_DATA.md`](../THIRD_PARTY_DATA.md).

## Rebuild

With the authorized source files restored to their documented locations:

```bash
make pipeline
make public-data
```

The export fails if required columns are missing. Public tables contain deterministic hashed IDs,
not customer names or seller identifiers.
