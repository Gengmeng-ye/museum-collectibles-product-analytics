# Documentation guide

The files in this folder answer different questions about the project:

| File | What it explains |
|---|---|
| [`data_dictionary.md`](data_dictionary.md) | Field names, units, missing values, and sources |
| [`methodology.md`](methodology.md) | Cleaning, statistics, K-Means, LDA, and sentiment evaluation |
| [`limitations.md`](limitations.md) | What the data and results cannot support |
| [`runbook.md`](runbook.md) | Commands for rebuilding and checking the project |
| [`sentiment_annotation_guide.md`](sentiment_annotation_guide.md) | Rules used for manual sentiment labels |
| [`legacy_code_audit.md`](legacy_code_audit.md) | What was found in the undergraduate code and documents |
| [`legacy_comparison.md`](legacy_comparison.md) | Which earlier conclusions were retained or rejected |

For results, start with [`../reports/analysis_report.md`](../reports/analysis_report.md). For the
interactive pages, see [`../dashboard/README.md`](../dashboard/README.md).
